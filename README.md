## Overview
<a id="overview"></a>

Color Sudoku is an innovative twist on the classic Japanese puzzle game, where players must strategically place colors instead of numbers into a 9x9 grid. This engaging game challenges players to ensure that no color appears more than once in any row, column, or 3x3 mini-grid. It is designed for both casual and experienced puzzle enthusiasts on the Windows platform.
